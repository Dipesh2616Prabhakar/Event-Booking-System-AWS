# Event Ticket Booking System (AWS Project)

## Project Overview
This is an AWS-based Event Ticket Booking System created in the AWS Academy Cloud Architecting Sandbox. The project allows users to manage and book event tickets using AWS services.

## AWS Services Used
- Amazon EC2: For hosting backend logic and web interfaces
- Amazon S3: For storing static content
- Amazon RDS: For database management
- AWS IAM: For secure user authentication and roles
- AWS CloudFront: For content delivery
- AWS CloudWatch: For monitoring

## Project Highlights
- Fully built using AWS services, no local coding required
- Demonstrates cloud architecture skills and service integration
- Sandbox environment valid for temporary testing
